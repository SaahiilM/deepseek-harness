## 23:21 — Swift shell compile fixes
- Learned: `swiftc` accepts only one `-target` per invocation — universal binaries
  need two compiles + `lipo -create`. Multiple `-arch` flags are not enough to set a
  deployment target.
- Learned: `-parse-as-library` forbids top-level statements, so `main.swift` cannot
  exist alongside it. Used `@main` on AppDelegate instead.
- Learned: **`@main` on an NSApplicationDelegate compiles but does NOT install the
  delegate** when the binary runs without nib/principal-class wiring — process runs,
  window never appears, zero output. Fixed with explicit `static func main()` that
  builds NSApplication, installs the delegate, and calls `run()`.
- Learned: NSObject inherits an instance method named `bind(_:)` (legacy Cocoa
  bindings) — the POSIX socket call must be spelled `Darwin.bind`.
